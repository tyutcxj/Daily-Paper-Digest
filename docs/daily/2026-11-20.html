Beyond Weight Updates: Evolving Agent Harnesses for Domain Specialization
相关度 ★★★★★ (0.65)

作者：BoHao Chen

发布日期：Fri,

类别：cs.AI

摘要

arXiv:2611.25380v1 Announce Type: new Abstract: Domain specialization of LLM agents is usually framed as a weight-update problem: collect trajectories, run reinforcement learning (RL) or supervised fine-tuning (SFT), and deploy a new checkpoint. We study a complementary axis: evolving the \textbf{agent harness}---the system prompt, tool schemas, skill library, and planning scaffolding---while keeping the policy frozen. We cast harness evolution as an RL-style outer loop and instantiate it with GEPA, a reflective evolutionary optimizer. The resulting harness adapters require no GPU training, are loadable per vertical domain, and compose with weight-based RL. Experiments with Codev, a Claude Code-style coding agent, on SWE-bench Verified, OfficeBench, and Terminal-Bench show a consistent pattern: weight updates give the strongest single-path gains, harness evolution recovers most of those gains at a small fraction of the compute, and combining both paths is best overall. We also analyze a failure mode of SFT-based specialization---shortened reasoning chains and increased truncation---and argue that harness adapters avoid it by construction. Our results position harness evolution as a practical, non-destructive complement to weight updates for vertical agents.

AI 总结

研究问题：LLM智能体领域专业化通常视为权重更新问题，本文研究互补方向：演化智能体harness（系统提示、工具模式等）而保持策略冻结。 主要方法：将harness演化作为RL风格外循环，用GEPA（反思性演化优化器）实例化，无需GPU训练，可加载到每个垂直领域并与权重RL组合。 关键贡献：实验表明权重更新单路径最强，harness演化以少量计算恢复大部分收益，两者结合最佳；且harness演化避免SFT的失败模式（推理链缩短和截断）。

Some Memories Must Fade: Persistence and Decay of User Memories in Model Parameters
相关度 ★★★★★ (0.60)

作者：Sanidhya Vijayvargiya, Rahul Lokesh

发布日期：Fri,

类别：cs.LG

摘要

arXiv:2611.25235v1 Announce Type: new Abstract: Parametric memory allows Large Language Models to internalize knowledge directly into their weights, offering a potentially powerful alternative to retrieval-based memory (RAG). However, existing approaches to parametric memory are difficult to deploy as they largely mirror the Continual Learning (CL) objective of retaining information indefinitely. This is neither sustainable nor sufficient for a memory system, which must govern knowledge across its lifecycle by retaining stable facts, reinforcing recurring observations, updating changed beliefs, and allowing transient information to fade. We propose a system for parametric memory management consisting of a memory substrate (handling information storage and forgetting) and a learned policy (what to remember, how deeply, and for how long). Our substrate is a fixed-capacity LoRA adapter that consists of k-hot rank combinations which store facts without catastrophic interference and maintain an independently controlled temporal decay, enabling outdated information to fade while long-term facts persist. On this substrate, we train a lightweight controller that governs each incoming user event to ensure the memory system reflects the user's true, updated belief state. To evaluate how memory systems manage user memory, we introduce a controlled dataset of long-horizon user trajectories with varying persistence of facts based on changing belief states and user-behavioral shifts, and probe queries that test recall while information is valid and abstention after it expires. Our policy learns to effectively manage user memory over its entire lifecycle, balancing recall and abstention to achieve 86% of oracle performance, unlike CL and RAG baselines that primarily default to one of the two behaviors. By providing the first system to manage memory directly in model weights, this work establishes a foundation for long-horizon parametric memory.

AI 总结

研究问题：大语言模型参数化记忆的持久与衰减管理问题。 主要方法：提出固定容量LoRA适配器作为记忆基底，结合k-hot秩组合与独立时间衰减，并训练轻量控制器管理用户事件。 关键贡献：实现稳定事实保留、过时信息衰减的记忆生命周期管理，并引入受控数据集评估。

EgoPass-Bench: Identifying Objects That May Affect the Wearer's Passage in Egocentric Video
相关度 ★★★★★ (0.55)

作者：Hongyu Wang, Chuhan Li, Congjin Xu, Xuandong Zhao, Hua Shen

发布日期：Fri,

类别：cs.CV

摘要

arXiv:2611.24995v1 Announce Type: new Abstract: Understanding an egocentric environment requires reasoning about how surrounding entities affect the observer's actions. Existing evaluations of multimodal foundation models (MFMs) examine observer localization, motion trajectories, and action feasibility, but leave the discovery and interpretation of evolving observer-entity interactions insufficiently assessed. We introduce EgoPass-Bench, a benchmark for observer-relative interaction understanding in real-world egocentric video. EgoPass-Bench comprises 284 manually reviewed evaluation clips recorded using Ray-Ban Meta (Gen 2) smart glasses and 2,201 distinct questions across five tasks assessing motion perception, interaction judgments about specified entities, and relevant-entity discovery without target cues. Our evaluation of eight frame-based and six native-video configurations reveals a pronounced discrepancy between motion perception and interaction understanding. The strongest evaluated model, GPT-6 Astra, correctly recognizes object motion in 91.37% of 394 comparisons involving the same targets, but correctly identifies changes in passage constraints in only 66.50%. Across all 574 entity-discovery questions, it trails the two-person human baseline by $23.65 \pm 7.45$ percentage points (paired 95% CI), while exceeding the always-empty baseline (36.76%) by at least 18.9 percentage points. Further analysis reveals frequent inclusion of entities that neither pose a plausible physical conflict nor constrain passage, showing that accurate motion recognition does not ensure reliable relevant-entity discovery.

Stop Going in Circles:Loop-Triggered Routing for System 1 Decision Agents
相关度 ★★★★★ (0.51)

作者：Zeming Yu, Huamin Ma, Yingyu Chen, Yuan Sun, Peng Hu, Yang Qin

发布日期：Fri,

类别：cs.AI

摘要

arXiv:2611.25363v1 Announce Type: new Abstract: System 1 decision models (represented by Jev) provide fast, low-cost action selection, but existing agent integrations do not reliably translate these local advantages into task completion. At certain points during execution, an agent may repeatedly select the same actions without making progress toward its goal. LLM-based policies offer strong reasoning capabilities that support planning within an agent, but invoking them at every step incurs substantial overhead. The effective coordination should therefore preserve Jev's fast local action selection while introducing LLM reasoning when execution stalls. We observe that recurring state-action pairs can signal stalled execution. In this paper, we introduce SimAudit, an LLM-based pipeline that audits success checkers against task instructions.
