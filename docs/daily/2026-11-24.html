ORDO: Fine-Grained Motion Understanding in Video LLMs via Order-Dependent Supervision
相关度 ★★★★★ (0.61)

作者：Jiaye Luan, Chaoning Zhang, Pengcheng Zheng, Dongshen Han, Sheng Zheng, Ping Guo, Caiyan Qin, Yang Du, Yang Yang

发布日期：Tue,

类别：cs.CV

摘要

arXiv:2611.28097v1 Announce Type: new Abstract: Video large language models (video LLMs) answer a wide range of questions about real videos, yet they remain weak at fine-grained motion such as whether an object speeds up or slows down. Existing methods train these models on synthetic motion clips, on order pretext tasks such as reordering shuffled clips, or with rewards that compare ordered and perturbed frames. None of them requires that the label be unrecoverable from the frames once their order is discarded, so a model can fit such data from static cues without learning to use frame order. We propose ORDO, a framework that builds this requirement into the training data. We define order-necessary supervision as data in which the unordered set of frames has the same distribution under competing labels, and we realise it for motion attributes with three constructions, time-reversal pairing, matched spatial extent and uniform interval coverage. A procedural curriculum of six motion primitives instantiates these constructions, and low-rank adapters of the language model are trained on it with an answer-level objective and self-distillation replay on real videos. With 4,000 synthetic clips, ORDO raises the mean accuracy over four motion benchmarks by +7.6, +4.9 and +5.1 points on Qwen3.5-9B, Qwen3-VL-8B and Molmo2-8B, while the same training with shuffled frames changes it by less than one point. Code and generator will be made publicly available.

AI 总结

研究问题：视频大语言模型对细粒度运动理解不足，现有方法未强制要求标签从无序帧中不可恢复。 主要方法：提出ORDO框架，构建顺序必要监督数据，通过时间反转配对、匹配空间范围、均匀间隔覆盖三种构造实现，训练语言模型低秩适配器。 关键贡献：在四个运动基准上平均准确率提升+7.6、+4.9、+5。

AutoPILOT: A Visual Agent Harness for Real-Time Gameplay
相关度 ★★★★★ (0.60)

作者：Mark Zhao, Pengcheng Wang, Rui Yang, Jiarui Yao, Xirui Jiang, Yuxi Chen, Bingxuan Li, Hanyang Chen, Ke Yang, Manling Li, Tong Zhang, Huan Zhang

发布日期：Tue,

类别：cs.AI

摘要

arXiv:2611.28202v1 Announce Type: new Abstract: Multimodal foundation models can play video games well when the game waits for them, but often fail when it keeps running. We find that much of this gap lies in the harness, which decides what the model sees, what it remembers, and how its outputs become actions over time. Existing harnesses such as VISTA improve the first two, yet turn each model call into at most one action, so the agent acts only as often as its model thinks. We introduce AutoPILOT, which changes the third: in each model call, the model can send a primitive action, start an open-loop macro, or write a closed-loop controller that keeps playing from the screen without further model calls until it hands control back. To evaluate agents in real-time games, we build AFK-Bench, 120 diverse browser games grouped by how they respond to inaction and playable in real time or with the clock paused. With GPT-6.1 Sol under the same budgets, AutoPILOT reaches 68.6% real-time success against 38.3% for VISTA, and on GameWorld it keeps 80.0% in real time while VISTA drops from 84.1% to 42.9%. Its gains hold across models, and it reaches VISTA's final success rate at a fifth of its API cost. Our results suggest that how a harness turns model outputs into actions over time is a central yet underexplored part of agent design, and we hope AutoPILOT and AFK-Bench will serve as a foundation for agents in a world that does not wait.

AI 总结

研究问题：多模态基础模型在实时游戏中因动作输出机制导致性能下降。 主要方法：提出AutoPILOT，允许模型在每次调用中输出原始动作、开环宏或闭环控制器，实现实时自适应控制。 关键贡献：构建AFK-Bench基准，AutoPILOT在实时成功率上显著优于VISTA，且API成本降低至五分之一。

Engram: Multi-Stage Memory for Agentic Tuning of Heterogeneous Models
相关度 ★★★★☆ (0.49)

作者：Huanran Li, Nhat X. T. Le, Kevin De Angeli, Yao Xuan, Alireza Vahdatpour, Djordje Gligorijevic

发布日期：Tue,

类别：cs.AI

摘要

arXiv:2611.28356v1 Announce Type: new Abstract: Large language model (LLM) agents can now tune neural networks, yet without cross-session memory they spend costly trials rediscovering known lessons. Reuse is difficult because production models differ in architecture, training setup and inference budget. We present Engram, a memory system that links past trial outcomes with the hypotheses and rationale behind them and assesses whether this evidence applies to the current model. An online agent curates evidence at the decision points where it is needed: Initial Guidance supplies validated lessons at the start, Session Retrieval supplies related past sessions before each batch of hypotheses is generated, and Trial Candidate Review checks each trial candidate against matching past trials. Between sessions, an offline agent distills validated lessons, making the memory self-improving. On two ads models, Engram reaches the 32-trial result of a no-memory control with 47% fewer trials and also ends with a better model on average.

AI 总结

研究问题：LLM agent调优异构模型时缺乏跨会话记忆，导致重复试验。 主要方法：提出Engram多阶段记忆系统，包括初始指导、会话检索、试验候选审查及离线蒸馏。 关键贡献：在广告模型上，用47%更少试验达到无记忆控制的32次试验结果，且最终模型更优。

arXiv:2611.28314v1 Announce Type: new Abstract: Abliteration is a widely used white-box attack against the safety alignment of large language models (LLMs). We propose INSEP, a defense that fine-tunes the model to reduce the separability of harmful and benign activations along the refusal direction. Abliteration estimates this direction as a difference in class means and projects it out. Reducing separability weakens the signal the attack relies on.
