# Changelog

## v1.0.0 (2026-05-22)

### ✨ Features

- 📄 arXiv paper fetching with category and keyword filtering
- 🤖 Multi-LLM support (OpenAI, Gemini, Claude, DeepSeek, vLLM)
- 📝 AI-powered paper summarization
- 📊 Trend analysis with TF-IDF keywords and word cloud
- 🎯 Personalized recommendations based on Zotero library
- 🖼️ Method figure extraction from PDFs
- 🌐 Responsive web interface with Bootstrap 5
- ⏰ APScheduler for daily automatic execution
- 📧 Email notifications (optional)

### 🛠️ Tech Stack

- Python 3.11+
- Flask + Bootstrap 5
- scikit-learn (TF-IDF)
- PyMuPDF (PDF processing)
- arxiv.py (arXiv API)
- Zotero API
